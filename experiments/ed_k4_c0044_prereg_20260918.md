## Predictions

1. 16/16 bit-identical (C0044 is invisible on N-MNIST by construction).
2. Per-sample engine latencies **equal to the 2026-09-05 build-4 table
   to 0.1 us** (mean 688.5, 554.8-815.8): the fix removes a gate term
   in the sweep's zeroing path and changes no cycle count.
3. Server overhead 117.5 us. PING build 4.
4. WNS +0.475 vs +0.508 on 2026-09-05: different project, global
   synthesis, same design — within normal placement variation.

## What would falsify

- Any latency difference: the C0044 change altered the sweep's timing
  (it must not), or the new project's block design differs from the old
  one in a way the .hwh diff cannot see.
- A CRC mismatch: same.
