# Block diagrams

Schematics for Chapters 1, 2, 4 and 5, generated by
`python3 experiments/figures/make_diagrams.py`. Each one is written as
`.svg` (edit this, in Inkscape or Illustrator) and `.png` (for quick
viewing and for pasting into notes).

These carry **no measured data**, unlike `../make_figures.py`: nothing here
needs regenerating when a result changes. Numbers that do appear are labels,
and each says where it comes from. To change a drawing, edit the code, not
the file.
