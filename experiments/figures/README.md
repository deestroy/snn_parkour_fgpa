# Figures for the results chapter

Generated by `make_figures.py` from the committed data files and logs
(never from typed-in numbers); re-run after any sweep or board pass.
Titles say sim or board. The two activity figures need the local trace
dumps (`golden/traces_*.npz`, `experiments/rate_sweep*/traces_*.npz`),
which are regenerable and not tracked.
