# Lessons from sign-off: what bit-identical simulation could not see (hand-maintained)

Each row: the symptom, why simulation passed anyway, the root cause, the fix, and the standing check that now catches it.

| # | symptom | where seen | why simulation passed | root cause | fix | standing guard | reference |
|---|---|---|---|---|---|---|---|
| 1 | ~62k LUTs for a 3k-LUT engine | synthesis | logic size is invisible to a functional testbench | multi-ported accumulator banks cannot map to BRAM and become distributed logic | one write + one read port per bank | sign-off rule in 5.3; utilisation gate in the build script | decisions.md 2026-08-18 |
| 2 | WNS -4.5 ns | timing | simulation has no delay | multipliers on address paths (bank offset, weight row) | stepped addresses, no multiplier on any address path | RTL lint targets in the ladder; WNS gate before any card | decisions.md 2026-08-18 |
| 3 | WNS -3.5 ns, 17 logic levels | timing | same | dividers in the spike decode | D0020 rev 2: addresses as packed fields | same | D0020 |
| 4 | WNS -0.42 ns on one endpoint | timing | same | LIF chain fed straight from BRAM output latches | re-registered BRAM outputs | same | decisions.md 2026-08-19 |
| 5 | board returns all-zero spikes on a timing-clean bitstream | silicon | $readmemh / two-stage init behaves in the simulator | two-stage weight-ROM initialisation silently zeroed by synthesis | single-stage init; weights baked into generated Verilog | sim/lint_synth_safety.sh (ladder); check_baked_weights.py | decisions.md 2026-09-05 |
| 6 | DMA unreachable from the CPU after a clean build | silicon | the PS configuration is outside the RTL | .xsa lost the DMA address map; board preset not applied | board preset + address map as load-bearing build inputs | build script parameter read-back; PING build check | D0014, D0015 |
| 7 | dense P=4 at the 64-geometry fails timing after passing at the 34-geometry | timing | geometry is a parameter; the 34-geometry closed | LIF update -> output-bit write in one cycle at the larger bank | rev 3 registered write | WNS gate; both geometries in the lint targets | decisions.md 2026-09-19 |
